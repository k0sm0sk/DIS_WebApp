## How to run
Run 'app.py' located at 'src/app.py' using:
#### MacOS
```bash
python3 app.py
```
#### Windows
```bash
python app.py
```
And go to the **local URL** 
```http://127.0.0.1:5000```
*Note that if the default url route for localhosts are 127.0.0.1 with a port usually defined as `:5000`. If you cannot access the file via this path, look at the output in the conosole of the terminal you are running the file from, and go to that URL.*
